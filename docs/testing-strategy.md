# Testing Strategy

Testing must cover the project's core reliability requirements.

## Backend

- Unit tests for services and eligibility rules.
- API tests for validation and authorization.
- Database integration tests.
- Data ingestion and validation tests.
- Security tests.

## Eligibility

Eligibility tests must include:

- Eligible profiles.
- Ineligible profiles.
- Missing profile information.
- Incomplete or unverified rules.
- Boundary conditions.
- Invalid or inconsistent input.

## Frontend

Flutter widget tests and end-to-end workflows should cover responsive layouts, localization, loading, error and empty states.

## Verification Rule

No test or implementation task is complete until relevant tests are executed successfully.
