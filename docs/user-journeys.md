# User Journeys

## Guest Discovery

Guests can browse, search and view published scholarship records without an account.

## Student Registration

A student registers, creates a profile and can confirm extracted profile values before eligibility evaluation.

## Eligibility Evaluation

A student requests a match. The system identifies eligible, ineligible, needs-more-information or uncertain results and explains each result.

## Guardian Assistance

Guardian access requires an approved relationship and specific permissions. The guardian consent and verification workflow remains unresolved.

## Administrator Verification

Administrators review source records, pending scholarship changes and verification history before publication.

## AI Assistance

The assistant responds only from approved scholarship information or clearly communicates when reliable source information is unavailable.
